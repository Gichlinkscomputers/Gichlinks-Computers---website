# Gichlinks Computers website

## Open it

Double-click `index.html` to open your website in a browser. It works without installing anything.

## First things to change

1. In `index.html`, replace every `254721 522 502` with your real WhatsApp number. Kenyan format example: `254712345678` — no `+`, spaces, or leading zero.
2. Change the product names and descriptions inside the three `product-card` sections.
3. Add prices or real product photos when you have them. Image files can go in an `images` folder, then use `<img src="images/laptop.jpg" alt="Laptop">`.

## Put it online for free (GitHub Pages)

1. Create a free GitHub account at https://github.com.
2. Create a new public repository named `gichlinks-computers`.
3. Upload `index.html`, `styles.css`, and `script.js`.
4. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, and `/ (root)`. Save.
5. GitHub will give you a website address such as `https://your-name.github.io/gichlinks-computers/`.

For a custom address such as `gichlinkscomputers.co.ke`, buy a domain from a Kenyan registrar and connect it in GitHub Pages' Custom domain setting.
